From a molecular question to a working calculation

A lot of my research involves writing software: building a polymer, following a proton through DNA, or working out how a complex molecule could be assembled. Here are the tools I've written and the collaborative projects I've helped develop along the way.

I've grouped them by the problems they tackle, with the most substantial work first in each section. Alongside research packages, you'll find code from individual papers, everyday simulation helpers, and a few experiments. Each entry links to the source, with documentation and papers where available.

01 / From monomers to the properties of a material.

Materials & polymers 5

Building polymers and amorphous structures is often the first step in a simulation. These tools handle that preparation and help connect the resulting structures to measurable properties.

Research software · Python

openmmpolymer ↗

LouieSlocombe/openmmpolymer

Starting from monomer SMILES, openmmpolymer builds, packs, and equilibrates polymer melts and blends with OpenMM. It then measures properties such as glass transitions, elasticity, and structure.

  • Polymers
  • OpenMM
GitHub ↗

Collaboration · Python

AmorphGen ↗

SMTG-Bham/AmorphGen

For materials without a crystal lattice, AmorphGen builds amorphous structures through random placement, melt-quench simulations, or a combination of the two. It can generate ensembles as well as individual structures.

  • Amorphous materials
  • Molecular dynamics
GitHub ↗ Docs ↗

Research software · Python

py-chargemol ↗

LouieSlocombe/py-chargemol

A Python implementation of Chargemol methods for turning electron densities into atomic charges, multipoles, and bond orders. It includes DDEC analysis and QDR charges for point-charge force fields.

  • Charge analysis
  • Force fields
GitHub ↗

Research software · Python / CUDA C++

vanderfast ↗

LouieSlocombe/vanderfast

GPU implementations of the D3 and D4 dispersion models, calculating the energies, forces, and stress associated with these interactions. ASE interfaces connect the calculations to molecular and materials workflows.

  • GPU computing
  • Dispersion
GitHub ↗

Collaboration · Python

solphin ↗

SMTG-Bham/solphin

Tools for investigating whether a material could work as a solar absorber. solphin prepares VASP and CASTEP calculations, then analyses optical absorption and the theoretical limits of photovoltaic efficiency.

  • Photovoltaics
  • Electronic structure
GitHub ↗ Docs ↗

02 / Following reactions with quantum nuclei.

Reactions & quantum dynamics 7

Much of my work asks how nuclei move during a reaction. These packages cover reaction paths, multiscale simulations, tunnelling, and isotope effects, along with the setup and analysis those calculations need.

Research software · Julia

HEOM.jl ↗

LouieSlocombe/HEOM.jl

A Julia package for following quantum probability through phase space. It solves Wigner–Moyal dynamics, hierarchical equations of motion, and Caldeira–Leggett models to study tunnelling, dissipation, and coupling to an environment.

  • Open quantum systems
  • Quantum dynamics
GitHub ↗

Research software · Python

reactiontools ↗

LouieSlocombe/reactiontools

The steps around a reaction-path calculation, brought together in Python: ASE paths and transition-state searches, PLUMED enhanced sampling, and reusable geometry, analysis, and plotting tools.

  • Reaction pathways
  • ASE
GitHub ↗ Docs ↗

Research software · Python

openmmnqe ↗

LouieSlocombe/openmmnqe

Simulations of quantum nuclei in OpenMM, using ring-polymer dynamics and adaptive quantum thermal baths. Includes workflows for calculating transmission coefficients and reaction rates.

  • Nuclear quantum effects
  • OpenMM
GitHub ↗ Docs ↗

Research software · Python

openmmqmmm ↗

LouieSlocombe/openmmqmmm

A way to place a quantum-mechanical description of a reactive region inside a larger molecular simulation. It couples ORCA and OpenMM, with optional machine-learning potentials, and is derived from the ASH modelling program.

  • QM/MM
  • Machine learning
GitHub ↗ Docs ↗

Research software · Python

autopcet ↗

LouieSlocombe/autopcet

For reactions in which protons and electrons transfer together. It solves for proton vibrational states and evaluates nonadiabatic PCET rate models, including kinetic isotope effects and models of electrochemical interfaces.

  • Proton-coupled electron transfer
  • Rate theory
GitHub ↗

Research software · Python

forcefill ↗

LouieSlocombe/forcefill

Helps prepare a simulation when ligand parameters are missing. It identifies unmatched residues and produces validated OpenMM force-field XML using GAFF, OpenFF, Espaloma, or supplied CGenFF parameters.

  • Force fields
  • Simulation preparation
GitHub ↗ Docs ↗

Research software · Python

nqetools ↗

LouieSlocombe/nqetools

Setup and analysis tools for nuclear quantum-effect calculations with i-PI. These include instanton workflows, tunnelling corrections, and plots of reaction rates and kinetic isotope effects.

  • i-PI
  • Tunnelling
GitHub ↗

03 / How much construction history is hidden inside a molecule?

Assembly theory & biochemistry 4

Work with the Emergence of Life group at Arizona State University on molecular complexity, assembly pathways, and biochemical reaction networks. The software brings the calculations and the chemistry together.

Collaboration · Python

AssemblyTheoryTools ↗

ELIFE-ASU/assemblytheorytools

A common Python interface for exploring how molecules, strings, and graphs can be built from reusable parts. It brings together assembly calculators, comparisons of shared structure, and pathway visualisation.

  • Assembly theory
  • Molecular complexity
GitHub ↗ Docs ↗

Collaboration · Python / Data

CBR-db ↗

ELIFE-ASU/CBRdb

A biochemical reaction database for studying the chemistry behind metabolic networks. It curates KEGG and ATLAS compounds and reactions, repairs problematic representations, and adds chemical and thermodynamic properties for analysis.

  • Biochemical reactions
  • Curated data
GitHub ↗

Collaboration · C++

ParallelAssemblyCpp ↗

ELIFE-ASU/parallelassemblycpp

Parallel C++ searches for minimal assembly pathways in molecules and strings, with exact searches and fast RePair upper bounds. If a search is interrupted, it reports the best result found so far.

  • Assembly algorithms
  • Parallel computing
GitHub ↗

Collaboration · Python

assemblycfg ↗

ELIFE-ASU/assemblycfg

Estimates upper and lower bounds on assembly complexity for strings and molecules. RePair construction pathways show which repeated fragments can be reused along the way.

  • Assembly bounds
  • Graphs & grammars
GitHub ↗

SMTG-Bham/PaperMinerToolkit

Tools for turning a collection of papers into a structured dataset. It searches research sources, gathers text and PDFs, and uses configurable text and vision models to extract the information specified in a recipe.

  • Machine learning

figrecover ↗

SMTG-Bham/figrecover

For the numbers that are available only in a published figure. It traces curves in images or reads vector paths in PDF and SVG plots, then exports CSV data in the original units.

  • Figure digitisation
  • Data extraction
